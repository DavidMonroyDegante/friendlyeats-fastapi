# FriendlyEats - Sprint 1

Aplicación web para consultar y administrar restaurantes.

## Tecnologías

- Python
- FastAPI
- Firebase Firestore
- HTML, CSS y JavaScript

## Requisitos

- Python instalado
- Firebase CLI
- Emulador de Firestore

## Instalación

1. Crear y activar un entorno virtual.
2. Instalar dependencias:

   pip install -r requirements.txt

3. Iniciar el emulador de Firestore.
4. Ejecutar la aplicación FastAPI.
